# Snake Web Game (Go + JS)

Игра "Змейка" с backend на Go и web-интерфейсом на Canvas.

## Возможности

- Управление: экранные стрелки, `WASD`, клавиатурные стрелки и свайпы
- Ускорение змейки после удержания стрелки управления 2 секунды
- Выбор цветовой палитры змейки
- Проход сквозь стены с появлением с противоположной стороны поля
- Змейка растет при наборе очков, а при столкновении с собой взрывается на частицы
- Плавно меняющийся фон игрового поля
- Звуки движения, предупреждение при столкновении с собой и расширенная фоновая мелодия Бетховена
- Ввод имени игрока при новом рекорде после столкновения змейки с собой
- 10 уровней скорости: каждый уровень проходится после 100 очков, на 10 уровне показывается победный фейерверк
- Текущий счет, лучший результат и топ-5 результатов
- Кнопки: старт, пауза, рестарт

## Локальный запуск

```bash
go run ./cmd/server
```

Откройте: `http://localhost:8080`

## Запуск в Docker

```bash
docker compose up --build
```

## Endpoint

- `GET /healthz` -> `ok`

## CI/CD

Workflow: `.github/workflows/ci-cd.yml`

- `test`: gofmt + go test
- `docker_publish`: публикация Docker image в DockerHub при push тега `v*`

Нужные GitHub Secrets:

- `DOCKERHUB_USERNAME`
- `DOCKERHUB_TOKEN`
